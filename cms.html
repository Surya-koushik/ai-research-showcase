There is no database and no admin server. The folder tree is the content model: drop a file in the right place, run one command, reload. This page reads the same manifest the site does, so it can never claim something the site does not have.

The whole workflow 1. Copy your file into the folder shown on the project's row. 2. Run python _tools/build_media_manifest.py from the site root. 3. Reload. Filenames set the order — hero is the tile image, everything else in screenshots/ becomes the gallery in name order.
