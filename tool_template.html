Inside the tool.

What it looks like in use, step by step, in the software it actually runs in.

From a documented standard to a verified record.

The plugin turns documented procedure — the L1 checklist, the classification sources, the update rules — into a controlled workflow inside Revit. It reads the model, evaluates the gates, proposes only the changes it is permitted to make, commits them through a single transaction, and writes down the result.

Sources
Procedure, L1 checklist, Uniclass and update rules
