HERO IMAGE SLOT
===============

Drop your generated hero images here and the site picks them up automatically:

  hero-light.png   -> shown when the site is in LIGHT theme (default)
  hero-dark.png    -> shown when the site is in DARK theme

Recommended: 1536 x 1024 (3:2) or square, PNG. Concept: "fragmented data
becoming one" in the brand gradient (violet #7C5CFF -> cyan #00D4FF).

Until these files exist, the animated canvas ("fragments converging") shows on
its own - the page never looks broken. When present, the image fades in over
the animation. No code change needed; just drop the two PNGs in this folder.
