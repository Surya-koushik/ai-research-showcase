# Construction Takeoff AI  (P24)

Type: Automation / MCP tool   |   Stage: Documentation & Takeoff
Showcase id: construction-takeoff-ai

Local-AI construction takeoff: classifies sheets, extracts schedules, counts symbols
and runs OCR across a drawing set to produce BOQ quantities. Runs on local models
(Ollama + PaddleOCR) via an MCP server; a benchmark harness tuned it across many models.
