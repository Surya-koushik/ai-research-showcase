02 / What it is

A weekly quality check reduced to one small, reliable action.

Phoenix checks the open Revit model, evaluates every result against five gates, identifies the exact failing elements, and records a structured weekly audit. The same standard, every model, every week.

02 / Procedure

From open model to certified record.

01

Open the model & click Run

The add-in lives on the Revit ribbon. One click starts certification against the currently open model. There is no setup and no external tool.

02

Run 22 deterministic checks

Naming, levels, grids, worksets, warnings, links and view templates are evaluated in sequence. Every check returns pass or fail and identifies the elements responsible.

03

Evaluate five quality gates

The checks roll up into five gates. Every gate must pass before the model can be certified Level 1 for the current week.

04

Generate the audit report

A shareable report records each check, its result and the offending elements so teams can move directly from finding to correction.

05

Record the weekly lock

A Supabase-backed record confirms completion. Compliance becomes visible without chasing teams for screenshots or spreadsheet updates.
