ADS Phoenix L1 Self-Certification Plugin

ProductionRevit plugin

A Revit plugin that checks an open model against 22 L1 requirements and creates a certification record.

02 / How it works

From documented requirements to a verified Revit record.

The plugin converts documented procedures, the 22-rule L1 checklist and classification sources into a controlled Revit workflow. It reads model data, evaluates five quality gates, proposes permitted updates, commits approved changes through a Revit API transaction, and records the verified result.

Sources
Procedure, L1 checklist, Uniclass/BSGD and update rules
Execution
C#/.NET add-in using the Autodesk Revit API
Output
Updated model state, certification record and audit trail
